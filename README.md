## 🗂️ Topics

### 🏗️ [Design Patterns](design-patterns.md)

Reusable solutions to commonly occurring problems in software design, organized into three categories:

- **Creational** — Factory Method, Abstract Factory, Builder, Prototype, Singleton
- **Structural** — Adapter, Bridge, Facade, Proxy, Decorator, Composite, Flyweight
- **Behavioral** — Strategy, Chain of Responsibility, Command, Mediator, Observer, State, and more

### 🏛️ [Architectural Patterns](architectural-patterns.md)

Strategies for organizing entire systems:

- MVC, MVVM, MVP
- Layered architecture, Client-server, Peer-to-Peer
- Event-bus, Publish–subscribe, Pipe-Filter, Broker, and more

### 🧱 [SOLID Principles](solid-principles.md)

Five principles for robust object-oriented design:

| Letter | Principle |
|--------|-----------|
| **S** | Single Responsibility Principle |
| **O** | Open/Closed Principle |
| **L** | Liskov Substitution Principle |
| **I** | Interface Segregation Principle |
| **D** | Dependency Inversion Principle |

### 🔀 [Programming Paradigms](programming-paradigms.md)

Different approaches to structuring programs:

- Imperative, Structured, Procedural
- Object-Oriented (class-based & prototype-based)
- Declarative: Logical, Functional, Database-driven
- Reactive, Event-Driven, and more

### ✨ [Clean Code](clean-code.md)

Best practices for writing code that is easy to read, maintain and extend.

### 📋 [Project Management](project-management.md)

Methodologies for managing software projects:

- Waterfall, Lean, Kanban, Scrum, Agile
